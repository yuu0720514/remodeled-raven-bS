# Remodeled Raven bS

**Remodeled Raven bS** is an enhanced version of **Raven bS**, originally created by **Stranger**.

It includes various improvements, optimizations, and additional features while maintaining compatibility with Minecraft Forge 1.8.9.

## Installation

1. Download the latest `.jar` file.
2. Place the `.jar` file into your Minecraft `mods` folder.
3. Launch Minecraft with Forge 1.8.9.

That's it—Remodeled Raven bS is now ready to use.
